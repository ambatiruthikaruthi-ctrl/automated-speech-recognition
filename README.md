# 🎙️ Automated Speech Recognition System

A Python-based speech-to-text application that captures spoken language through a microphone and converts it into written text.

## 🚀 Features

* 🎤 Captures speech through a microphone
* 📝 Converts speech into text
* 🔊 Handles spoken input in real time
* ⚠️ Handles unclear audio and connection errors
* 💻 Simple and beginner-friendly Python implementation

## 🛠️ Technologies Used

* Python
* SpeechRecognition
* PyAudio
* Google Speech Recognition API

## 📂 Project Structure

```text
automated-speech-recognition/
│
├── speech_to_text.py

```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ambatiruthikaruthi-ctrl/automated-speech-recognition.git
```

Go into the project folder:

```bash
cd automated-speech-recognition
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run:

```bash
python speech_to_text.py
```

The application will access your microphone, listen to your speech, and convert it into text.
